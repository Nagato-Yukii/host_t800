# 验证记录（2026-11-16）

已完成实现和短程验证，未进行8k/10k完整训练，未证明成功率或真机可执行性。

- **资产/PD**：25个仿真 actuator 的 Kp/Kd 与 `pd.json` 逐项相等；base task 在4环境下可步进，无辅助外力。
- **自动测试**：5项 unittest 通过：课程边界、语义PD映射、512倒地姿态及531动作覆盖、5/7秒时序、悬空/躺卧/高速状态不算站立。
- **GPU smoke**：8环境400控制步，9次重置；四类姿态均采到，初始根高度约0.083–0.271m；观测/奖励有限，每步上拉力约666.99N，最大350步。
- **真实力验证**：iteration 0/999/1000/7000/8000/9000 的实际 MuJoCo body wrench 均符合固定比例；X/Y外力为0。
- **局部重置**：只重置指定环境，其他环境关节状态不变。
- **终止特征**：故意触发异常终止，AMP使用实际终止状态，与新episode观测不同，终止惩罚生效，reset后恢复倒地。
- **数据采样**：20000次采样覆盖全部531条；相邻帧不跨片段；输入原速从30Hz重采样为50Hz，115686帧。姿态部分专家特征与仿真实时特征最大误差4.77e-7。
- **PPO/AMP**：16环境、16次更新、6144条控制转换；所有TensorBoard标量有限，跳过非有限batch数为0；reward各项、AMP判别器和课程/终止指标已实际写入控制台及TensorBoard。
- **续训**：加载 `model_16.pt`，继续iteration16、17，生成`model_18.pt`；iteration计数是“下一次要运行的更新”，不从0重启课程。

日志位置：`logs/smoke.log`、`logs/base_check.log`、`logs/integration.log`、`logs/tests.log`、`logs/train_validated.log`、`logs/resume_validated.log`。结构化结果：`docs/validation.json`。
